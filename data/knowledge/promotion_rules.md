# 促销活动规则

## 一、会员等级与权益

### 标准会员
- 注册即成为标准会员
- 积分倍率：1倍（消费1元=1积分）
- 生日当月享95折优惠
- 每月1张满100减5元优惠券

### VIP会员
- 升级条件：累计消费满5000元
- 积分倍率：2倍（消费1元=2积分）
- 专属9折优惠（部分商品除外）
- 每年3次免运费退货
- 延长保修6个月
- VIP日（每月8号）额外9折
- 优先发货

### 企业会员
- 升级条件：企业认证+年采购额满2万元
- 积分倍率：3倍（消费1元=3积分）
- 专属折扣（根据采购量协商）
- 月结支付额度
- 专属商务经理
- 延长保修1年
- 批量采购优惠

## 二、优惠券规则

### 获取方式
- 新用户注册：20元无门槛券
- 每日签到：连续7天获得5元券
- 评价商品：每次获得3元券
- 分享商品：每次获得2元券
- 活动赠送：不定期发放

### 使用规则
- 每笔订单最多使用1张优惠券
- 优惠券不找零、不兑现
- 优惠券可与积分叠加使用
- 特价商品可能不支持优惠券（以商品标注为准）
- 优惠券过期作废，不予补发

### 常见面额
- 满100减10、满200减25、满500减60
- 满1000减150、满2000减350
- 无门槛券：5元、10元、20元

## 三、满减活动

### 常规满减（长期有效）
- 满200减20
- 满500减60
- 满1000减150

### 大促满减（限时活动）
- 双11、618、年货节等
- 满300减50、满600减120、满1200减300
- 活动时间以公告为准

## 四、积分体系

### 积分获取
| 行为 | 积分 |
|------|------|
| 消费1元 | 1-3分（按会员等级） |
| 每日签到 | 5分 |
| 评价商品 | 10分 |
| 分享商品 | 5分 |
| 邀请好友注册 | 50分 |

### 积分使用
- 积分抵扣：100积分=1元，上限为订单金额30%
- 积分兑换：兑换优惠券、实物礼品
- 积分抽奖：100积分/次

### 积分有效期
- 标准会员：积分当年有效，年底清零
- VIP会员：积分2年有效
- 企业会员：积分永不过期

## 五、限时活动

### 秒杀活动
- 每日10:00、14:00、20:00三场秒杀
- 每人每场限购1件
- 秒杀价不与其他优惠叠加

### 拼团活动
- 2人成团享8折，5人成团享7折
- 24小时内未成团自动退款
- 拼团商品不参与积分抵扣

### 预售活动
- 支付定金享尾款优惠
- 定金翻倍规则以活动页面为准
- 预售商品不支持7天无理由退货
